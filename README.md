# Utilora 在线实用工具箱

Utilora 是一个免费、轻量、无需登录的在线工具集合。

所有数据均在浏览器本地处理，不会上传到服务器。

## 在线访问

https://utilora.github.io/

## 已有工具

- 文本字符、字数和行数统计
- JSON 格式化与压缩
- Unix 时间戳转换
- 随机密码生成
- 英文大小写转换

## 技术说明

项目使用纯前端技术开发：

- HTML
- CSS
- JavaScript
- GitHub Pages

无需安装依赖，也不需要服务器或数据库。

## 本地运行

下载项目后，直接使用浏览器打开 `index.html` 即可。
